# FoodTracker

Android app for tracking daily food intake, water and steps. Developed in January–May 2026 as my bachelor's thesis project.

## Features
- Log meals by meal type with calories and macros
- Barcode scanning (ML Kit + CameraX) to find saved foods or create new ones
- Custom foods and recipes with ingredients
- Water tracking with custom containers
- Manual step entry with estimated calories burned
- Personal profile with automatically calculated daily goals
- Weekly statistics with charts

## Tech stack
Kotlin, Room (SQLite), Coroutines, CameraX, ML Kit, MPAndroidChart, Material Components

## Run
Open the project in Android Studio and run on an emulator or device (Android 8.0+).

Built with the help of AI tools.
